**Palm Coast Stories** — an original top-down open-world crime mini-game (no Rockstar assets): explore a city on foot or by stealing cars, dodge traffic and pedestrians, raise a wanted level and outrun the police, take on 3 story missions, fight with fists or a pistol, and save your progress. Built by an AI agent (Hermes Agent) for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
